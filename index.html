About

I'm a first-year bachelor's student studying Computer Science, and right now I'm working on the fundamentals.

I started with Python through Harvard's CS50P course, and I try to turn each new idea into a small program that actually runs. From there I've been moving into data structures, Git and GitHub, and the basics of building for the web.

My longer-term interest is AI and machine learning. I don't want to skip ahead to it, so for now it's a direction I'm heading in rather than something I claim to know. The plan is to get comfortable with programming, algorithms and data structures first.

This site is a snapshot of where I am today. I'll keep updating it as I learn.
